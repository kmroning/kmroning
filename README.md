# @kmroning

Кибербезопасность и OSINT. Работа с открытыми источниками с 2021 года.

## Профиль

Практикующий OSINT-специалист. Начинал в сообществе кибербезопасности:
обсуждения на площадке ВКонтакте, затем Telegram-сообщества, где перешёл
к системной работе с открытыми источниками.

## Методика

- **Слежка по открытым источникам** — отслеживание активности и связей по публичным данным
- **Поиск зацепок** — выявление следов, совпадений и косвенных признаков
- **Верификация** — подтверждение данных по независимым источникам
- **Таймлайны** — восстановление хронологии событий
- **Оценка достоверности** — разделение факта, предположения и пробела
- **Минимизация** — сбор только необходимых полей
- **Маскирование** — телефон, адрес и данные третьих лиц по умолчанию скрыты

## Опыт

Практические OSINT-кейсы с 2021–2022 гг. Верификация частных лиц
и публичных персон. Работа с гражданскими запросами. Проверка информации
по открытым источникам.
